# Eaudestore — каталог парфюмерии

**[Открыть публичный каталог](https://eaudestore-vladislav-catalog.zemanovvlad351.chatgpt.site)** — доступен всем посетителям; платформа Sites может запросить вход через ChatGPT. Исходники и файлы в этом репозитории доступны без входа.

Поиск по 45 657 позициям из прайса Eaudestore: фильтры по объёму, концентрации, цене и тестерам, сортировка и избранное. Адаптирован для телефона и компьютера. Палитра: приглушённый синий, песочный, терракотовый и серо-голубой.

## Как обновляются цены

Онлайн-каталог читает [Google-таблицу продавца](https://docs.google.com/spreadsheets/d/1oBChZo1L0iVX8IZy4ia8n74nJBjBrX0v099Q8Lpd5KI/edit) из [закреплённого поста](https://t.me/eaudestore/6) при открытии и по кнопке «Обновить цены». Сервер повторно использует ответ не более 60 секунд. Google также может кешировать экспорт.

При ошибке загрузки или изменении структуры источника остаётся последняя сохранённая копия с датой. В разделе «Обновления» отображается сравнение цен с предыдущей копией. Избранное и последний успешный прайс сохраняются в браузере и не синхронизируются между устройствами.

Скидки из [поста от 05.11.2026](https://t.me/eaudestore/1378) внесены отдельно. Объём и формат флакона там не указаны, поэтому они не заменяют произвольную цену из таблицы. Новые Telegram-посты автоматически не считываются.

## Локальный запуск

Нужен Node.js 22 или новее. Внешних зависимостей нет.

```sh
npm test
npm run build
npm run start
```

Открыть http://127.0.0.1:8765. Для обновления цен серверу нужен доступ к Google Sheets.

## Структура

- `page.html` — разметка и стили.
- `app.js` — поиск, фильтры, избранное и обновление данных.
- `catalog-core.mjs` — разбор CSV, очистка данных, транслитерация и сравнение цен.
- `catalog.json` — базовый снимок прайса.
- `build.mjs` — сборка автономного HTML и Cloudflare Worker.
- `worker/index.js` и `dist/` — результат сборки, в Git не хранятся.
- `downloads/` — готовые файлы.

Для обновления базового снимка заменить `catalog.json` после проверки данных и даты, затем выполнить сборку и тесты. Для смены источника изменить `SHEET_ID` в `catalog-core.mjs`. Не заменять рабочие данные пустым или повреждённым прайсом.

GitHub хранит исходники и файлы для скачивания. Серверное обновление цен работает на опубликованном сайте и при локальном запуске; обычный GitHub Pages не запускает Worker.
