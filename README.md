# Eaudestore — каталог парфюмерии

**[Открыть сайт каталога](https://vladnes7.github.io/eaudestore-catalog/)** — GitHub Pages, доступен всем без входа и регистрации.

Поиск по 45 657 позициям из прайса Eaudestore: фильтры по объёму, концентрации, цене и тестерам, сортировка и избранное. Адаптирован для телефона и компьютера. Палитра «Небо»: #04202E, #0A3C55, #0F5E83, #1786B4, #4FB3DA, #98D5EE и #E1F2FA. Все семь оттенков используются в фоне, панелях, рамках, акцентах и тексте. Шрифт Manrope, перелив названия, раскрывающаяся заливка кнопок и плавная смена разделов. Кнопка паузы убрана; системные настройки уменьшения движения учитываются. В ссылках на канал и продавца добавлены значки Telegram.

## Как обновляются цены

Онлайн-каталог читает [Google-таблицу продавца](https://docs.google.com/spreadsheets/d/1oBChZo1L0iVX8IZy4ia8n74nJBjBrX0v099Q8Lpd5KI/edit) из [закреплённого поста](https://t.me/eaudestore/6) при открытии и по кнопке «Обновить цены». На GitHub Pages браузер получает открытый CSV напрямую из Google, без сервера и без авторизации. Google может кешировать экспорт. Локальный Worker повторно использует свой ответ не более 60 секунд.

При ошибке загрузки или изменении структуры источника остаётся последняя сохранённая копия с датой. В разделе «Обновления» отображается сравнение цен с предыдущей копией. Избранное и последний успешный прайс сохраняются в браузере и не синхронизируются между устройствами.

Скидки из [поста от 05.11.2026](https://t.me/eaudestore/1378) внесены отдельно. Объём и формат флакона там не указаны, поэтому они не заменяют произвольную цену из таблицы. Новые Telegram-посты автоматически не считываются.

## Локальный запуск

Нужен Node.js 22 или новее. React-компонент кнопки рендерится при сборке; React не загружается в браузере. Настройка TypeScript, Tailwind и структуры shadcn описана в [components/ui/README.md](components/ui/README.md).

```sh
npm ci
npm run typecheck
npm test
npm run build
npm run start
```

Открыть http://127.0.0.1:8765. Для обновления цен серверу нужен доступ к Google Sheets.

## Структура

- `page.html` — разметка интерфейса.
- `styles.css` — базовое адаптивное оформление; `dark.css` — тёмная тема и эффекты.
- `components/ui/interactive-hover-button.tsx` — React-компонент кнопки из задания; `demo.tsx` — пример импорта.
- `tailwind.css`, `components.json`, `tsconfig.json`, `lib/utils.ts` — Tailwind, shadcn-совместимые пути и TypeScript.
- `scripts/render-button.tsx`, `ui-effects.js` — сборка компонента и подключение к нативным кнопкам и ссылкам, управление анимацией.
- `assets/motion/` — слой взаимодействий из design-taste-frontend, в сборке встраивается в HTML.
- `app.js` — поиск, фильтры, избранное и обновление данных.
- `catalog-core.mjs` — разбор CSV, очистка данных, транслитерация и сравнение цен.
- `catalog.json` — базовый снимок прайса.
- `build.mjs` — сборка автономного HTML и Cloudflare Worker.
- `worker/index.js` и `dist/` — результат сборки, в Git не хранятся.
- `downloads/` — готовые файлы.
- `docs/` — опубликованный сайт GitHub Pages; сборка создаёт его автоматически.

Для обновления базового снимка заменить `catalog.json` после проверки данных и даты, затем выполнить сборку и тесты. Для смены источника изменить `SHEET_ID` в `catalog-core.mjs`. Не заменять рабочие данные пустым или повреждённым прайсом.

GitHub Pages публикует папку `/docs` ветки `main`. После изменения интерфейса или базового снимка выполнить `npm run build`, включить обновлённый `docs/index.html` в коммит и отправить его в `main`. GitHub опубликует новую версию автоматически. Worker используется только при локальном запуске или отдельном серверном размещении; сайту на GitHub Pages он не нужен.
